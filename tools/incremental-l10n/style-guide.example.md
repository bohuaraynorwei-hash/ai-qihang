# 风格指导（示例）

## 人称
- 对玩家一律用「你」，不用「您」。
- 系统自述用「我们」。

## 语气
- UI 按钮、菜单：动词开头，简短有力（如「保存」「继续」）。
- 叙事文本：自然口语，不书面化。
- 报错：一句话说清「发生了什么 + 玩家该怎么办」。

## 标点与格式
- 统一全角标点（，。！？），不用半角。
- 省略号用「……」不用「...」。
- 数字和英文两边保留半角空格（如「12 秒」「HP 100」）。

## 专有名词
- 技能名、道具名、角色名保留英文原名，不翻译。
- 其余术语译法以术语表为准。

## 长度
- 每条译文不超过源文 1.2 倍，超长请精简。
